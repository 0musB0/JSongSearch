# Andrej Karpathy's 4 Core LLM Coding Principles (`andrej-karpathy`)

## 1. Think Before Coding
- State your assumptions clearly before writing any code. Analyze the requirements, edge cases, data structures, and failure modes. Don't rush into generating code.

## 2. Simplicity First
- Always choose the simplest possible implementation that correctly solves the problem. Eliminate over-engineering, unnecessary configuration files, and premature abstractions.

## 3. Surgical Changes
- Make precise, minimal, high-impact code modifications. Touch only what is necessary, preserve existing working code and comments, and avoid introducing side effects across the codebase.

## 4. Goal-Driven Execution
- Focus relentlessly on the end goal and working verification. Test your assumptions, execute verification scripts or tests immediately after making changes, and confirm end-to-end success.
